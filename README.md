# 统一监控与岗位交接中心 · 演示站（Demo）

面向客户技术负责人的**技术集成与需求调研**演示原型。纯静态站点（HTML + CSS + 原生 JS），**零依赖、零构建、离线可用**，双击 `index.html` 即可打开。

## 一、打开方式

- 方式一：直接双击 `index.html`
- 方式二：在本目录执行 `python -m http.server 8777`，浏览器访问 `http://127.0.0.1:8777`

> 建议用 Chrome / Edge 打开，语音告警（Web Speech API）在 Chromium 内核下效果最佳。

> 📊 **图表口径与联动关系**：全站所有可视化的数据来源、计算口径、绘制基元与相互联动，见图文版 **[`图表逻辑关系说明.html`](图表逻辑关系说明.html)**（25 张图全部由引擎真实数据渲染、可交互悬停、带编号标注，交接/评审首选），文字版见 [`图表逻辑关系说明.md`](图表逻辑关系说明.md)。改动任一图表口径时请同步更新这两份文档。

## 二、已确认的落地口径（按客户意见）

| # | 客户要求 | 落地实现 |
|---|---|---|
| 1 | **不要短信，只有邮件** | 全站已移除短信通道，`NOTIFY_RULES` 中仅保留邮件 / 邮件+语音；页面明示「短信通道：未启用」 |
| 2 | **SMTP 网关配置写死在代码中** | 网关参数为后端实现细节，`data.js` 中保留 `SMTP_FIXED` 作为实施对接口径，**页面不展示、无输入框** |
| 3 | **邮件内容写死，另给一个邮件内容展示页【演示用】** | 模板由后端渲染；`mail.html` / `alerts.html` 只展示**收件人在邮箱中看到的效果**（主题、收件范围、正文）与投递记录，不展示源码与网关参数 |
| 4 | **附件统一保存到客户指定服务器** | 上传的存证直接落到客户指定服务器，页面保留上传、校验、指纹留痕与交接流程，**不展示服务器地址、挂载点与配额等实现参数**（仍见 `data.js` 的 `STORAGE_FIXED`） |
| 5 | **采集与调度不给配置，只要调用日志** | 页面取消全部配置入口，只保留「各子系统数据对接情况总览 + 逐条调用日志」（按子系统/结果/时间筛选、实时追加、点击查看详情报文与处置建议） |
| 6 | **写死的内容不在网页中展示** | 全站已清理所有「写死 / 硬编码 / 配置文件代码块 / 页面不可修改」类描述与面板，页面只呈现可被使用的功能与运行数据 |

## 三、信息架构（按 09-24 需求对齐更正）

> 依据《需求对齐清单-0924》第 2 节，产品形态由「一个平台装下所有模块」更正为
> **「一个子系统 = 一块专属大屏」**，多块屏共同构成「监控室」。站点导航已按此三层结构重构。

| 层级 | 内容 | 本站对应 |
|---|---|---|
| **监控室** | 多屏轮播、屏清单速览 | `wall.html`（自动滚动 / 手动切换 / 大字号 / 全屏 / 报警演练） |
| **专属大屏层** | 一个子系统一块屏，**按屏排期** | P2 **Output（OP）大屏** `output.html`（按《Output 大屏（周维度追踪）需求提示词》落地：以「周」为单位、周六起始、按 PKG Type 监控目标/实际累计，达标·临界·超标预警）；其配套 **周维度累计表独立页** `op-table.html`（查看 / 对账 / 导出）与 **OP 目标与权限配置页** `op-config.html`（PKG Type 维护 / 每周目标数量 / 预警分口径·夏令时；原「部门可见范围」配置域已于 2026-10-08 下线）；**WIP 在制品看板** `wip.html`（按 PDF §4「WIP」落地：PKG Type × 工序、数量/Earn 双口径、二级钻取筛选、指标报警配置，样式为浅色卡片风动效版，区别于客户现有深蓝大屏）；**次品管理 · 质量预警大屏** `defect.html`（按 10-07《质量数据可视化预警系统需求》落地：真实 PPM 数据三级下钻，见下表专条） |
| **屏内标配能力** | 预警 + 邮件，**各屏复用为统一组件** | `alerts.html`（阈值 / 周期 / 系数、屏幕变红 + 强制弹窗 + 语音）、`mail.html` |
| **平台底座** | 数据接入、采集调度、用户权限 | `systems.html`、`ingest.html`、`users.html` |
| **分析与归档** | 跨屏的分析与留存能力 | `analytics.html`、`monthly.html`、`archive.html` |

**侧边栏（可自动隐藏）**：默认收起为 66px 图标条，鼠标移到最左侧即浮出完整目录（含分组标题与交付状态标签 P2 / 配置 / 标配 / 暂缓），移开自动收起；点底部图钉可固定常驻，状态记入本地存储。浮出时采用「占位层 + 绝对定位」实现，**不会挤压右侧内容区**造成页面抖动。

**排期占位**：侧边栏中「待排期 / 暂缓」的看板为灰色不可点击，点击提示需 09-29 与客户确认后开工，与会议确定的「小步快跑、按屏排期」策略一致。

**看板页「重点事项置顶区」**：监控总览以统计为核心，页面最上方集中展示**待处理 / 异常 / 逾期 / 关键词命中**四类需重点关注事项（醒目色卡 + 徽标 + 呼吸圆点，点击可展开全部明细），其余常规统计 KPI、图表与明细表依次排列在重点区下方，保证「重点突出、层次清晰」。该区域由 `common.js` 的 `prioBand()` 统一渲染，且随筛选条件联动刷新。
**Output（OP）大屏已按客户要求移除重点事项置顶区**，直接进入「筛选 → KPI → 累计对比图 → 数据刷新」；**周维度累计表**与**异常报警 · 周维度**两张表均已拆到独立页 `op-table.html`。

演示过程中可在页面上自行维护的业务数据同样集中在 `data.js`（种子数据），页面改动保存在浏览器 LocalStorage：

## 六、适老化设计（使用者以 40 岁左右为主）

- 正文基准字号 16px，卡片标题 17–19px，关键数值 34px，避免小字密排。
- 浅色主题：页面底色 `#f2f5fa`，卡片纯白，文字/背景对比度 ≥ 4.5:1。
- 控件高度 ≥ 42px，点击热区充足；表格行高宽松、悬停高亮。
- 状态以「色块 + 文字 + 图标」三重标识（正常 / 告警 / 严重 / 离线），不依赖单一颜色。
- 全部图标为内联 SVG，无外部 CDN，断网也能正常演示。
