# 统一监控与岗位交接中心 · 演示站（Demo）

面向客户技术负责人的**技术集成与需求调研**演示原型。纯静态站点（HTML + CSS + 原生 JS），**零依赖、零构建、离线可用**。

- 打开方式：双击 `index.html`，或在本目录执行 `python -m http.server 8777` 后访问 `http://127.0.0.1:8777`（建议 Chrome / Edge）
- 产品形态：**一个子系统 = 一块专属大屏**，多块屏共同构成「监控室」
- 数据说明：Output / WIP / 次品管理三块大屏已接入客户真实报表数据（由根目录 `.extract-*.py` 抽取脚本生成 `assets/js/*-real-data.js`），其余为演示样例
- 页面上的业务配置保存在浏览器 LocalStorage（键前缀 `ohd_`），不影响任何真实系统

## 二、大模块功能描述

### 1. Output（OP）大屏（output.html）

- 以「周」为单位（周六起始），按 PKG Type 监控累计目标 vs 累计实际，默认「双部门 3×2」六图布局（LEAD / NON-LEAD × 颗数 / BGA·LGA 标准 I/O 当量 / Earn 金额），同一行共用 Y 轴便于横向比较
- 目标线虚线 / 实际线实线，超标日红柱 + 脉冲标记；**整张图可直接点击**，跳转周维度累计表并自动定位该日
- BGA/LGA 走「料号 I/O 加权」口径（实际结果 = PKG_I/O × 数量 ÷ 225），LEAD 部门按颗数并入主图；PLATING 部门两图独立（颗数图 / DEFLASH 金额图）
- 报警判定口径 = (累计实际 + 在制 WIP) vs 累计目标（WIP 不绘图、只参与判定）
- 底部「数据刷新」标注本周真实 / 演示数据来源，支持手动刷新

### 2. 周维度累计表（op-table.html）

- PKG Type × 逐日累计（目标 goal / 实际 total / 预留 FE total）+ 底部 Earn 目标 / Earn 实际（万元）两行
- 单元格按差额着色（达标绿 / 临界黄 / 超标红 +「超 / 警」角标），未来日期斜纹「无数据」；「含 WIP 抵扣」列按报警判定口径着色
- 支持年份 / 周别 / 视角部门 / PKG Type 筛选与 Excel 导出；接收 OP 大屏图表点击的「定位日」高亮

### 3. OP 目标与权限配置（op-config.html）

- **① PKG Type 维护**：显示名 / 小分类（封装料号）逐料号单价（含产出占比参考、一键填充系统默认价）/ 默认周目标 / 黄灯红灯阈值（逐品类独立配置）/ 启用
- **② 每周目标数量**：按年份 + 周别逐品类填写，支持复制上周 / 清除回落默认
- **③ 预警分口径 · 夏令时**：Earn 金额递进链口径（递进基准 / 容差 / 手动修正「逐日生效」按钮，过去日期禁用）/ 夏令时开关
- **④ 料号 I/O 维护**：维护 OP 料号 ↔ PKG_CODE ↔ PKG_I/O，支持从客户 IO 表一键带入、输入 PKG_CODE 自动带出 I/O 值、Excel 导出
- 需 Output「编辑」权限，否则整页只读

### 4. WIP 在制品看板（wip.html）

- 一级：按品类展示各工序 WIP，数量（K）/ Earn（万元）双口径切换 + 5 项 KPI 数字滚动 + 「工序 × PKG Type 热力矩阵」+ 工序排行堆叠条 + Hold 批次跑马灯
- 热力矩阵品类列头可点击，联动右侧「工序 WIP 排行」按该品类的客户指定站点清单重算（再点恢复全部）；站点在 WIP 品类配置中维护并可配置**预警值**，排行中超预警站点标记 ⚠
- 二级（点击工序 / 矩阵格进入右侧抽屉）：pkg type / size / 封装料号 / 机台 / Bank / 仅看 Hold / 仅看解冻超时 / 关键字筛选，排序 / 分页 / Excel 导出
- 批次列表含**金额（元）**列（数量 × 单价，与 Earn 口径联动）；支持 BE CT / OTD 报警阈值配置，触发行整行高亮
- 排序行提供**人工计算**（勾选批次弹出金额明细与总价）与**自动计算**（输入需求量或预算总价，系统按当前排序自动取批、末批部分取用）两个按钮
- 接入「COMP 塑封料出库解冻」演示数据（批次级解冻状态 / 起止时间 / 超时高亮，标注「演示补充 · 非客户初始需求」）

### 5. WIP 品类配置（wip-config.html）

- 维护每个 PKG Type 的：显示名 / 单价口径（OP PKG Type）/ 是否在热力矩阵显示 / 排行联动站点清单
- 站点清单每行 = 站点显示名 + 工序代码（逗号分隔）+ 预警值（颗），支持**拖拽排序**（⠿ 手柄，顺序即排行展示顺序）
- 配置即时生效并本地持久化，可恢复默认

### 6. 次品管理 · 质量预警（defect.html）

- 一级：BGA Top Defect PPM Trend 多系列折线图（16 类别 × 52 周，图例勾选显隐、工序筛选 MOLD / MARK / ICOS、部门按登录账号自动过滤）
- 二级：设备维度机台树状图（根 = 类别周合计 PPM，子节点 = 各 Mold 机台），机台节点带**报修 / 换模近 24h 角标**，点击弹出 24h 明细（报修单号 / 故障描述 / 模具更换记录）
- 三级：机台 × 料号透视表（PPM 着色 + 同料号跨机台 PPM 反查列 + **预警设置列**——按机台配置 PPM 阈值，超标标 ⚠）+ Package 明细两个入口；页顶「近 24h 报修 / 换模」统计卡同样可点击查看明细
- 四级：料号跨机台 PPM 分析（6 项 KPI + 各机台 PPM 柱状图 / 次品占比环形图并排 + 跨机台明细表）
- 阈值口径：红线 2000 PPM / 预警线 3000 PPM；机台级 500 / 350

### 7. 次品项配置（defect-config.html）

- 单屏维护次品项主数据：部门分段筛选 + 工序筛选 + 表格（代码 / 名称 / 部门 / 工序 / 绑定设备）
- 新增 / 编辑弹窗维护名称 + 代码 + 部门 + 工序 + 设备绑定多选；Excel 导出；仅管理员可编辑

### 8. 日志管理 · 生产日志（logs.html）

- 按客户截图 1:1 还原的只读静态展示：班次回看（上一个交班班 / 回到当前班）、From / Date 头部、LEAD / NON-LEAD 双部门切换

### 9. 屏内标配能力（alerts.html / mail.html）

- 预警组件：紧急联系人 + 子系统（OP / WIP / 次品管理）× 报警级别（红 / 黄）× 联系人多对多绑定；红色报警 = 红屏 + 强制弹窗 + 语音，黄色报警 = 仅邮件
- 邮件组件：两套邮件效果切换预览（主题 / 收件范围 / 正文）+ 近期投递记录

### 10. 平台底座（users.html）

- RBAC：用户管理（多角色 / 数据范围 / 停用重置）、角色权限矩阵（13 模块 × 6 操作）、操作日志留痕

### 11. 分析与归档（monthly.html / archive.html）

- 自动月报：按月汇总告警总量 / TOP 高频异常 / 处置情况 / 根因聚类，支持章节配置与 PDF·Excel 导出
- 历史归档：按子系统分类浏览归档日志，支持导出

### 12. 我方优势 · 平台价值（advantage.html）

- 7 大核心优势卡（多源打通 / 批次追溯 / 质量分析 / 告警工单闭环 / OTD / 可复用大屏 / 落地经验）+ 已落地系统（设备报修 / 模具管理 / COMP 塑封料解冻）+ 告警→工单闭环流

## 三、我方优势在 WIP 模块中的能力对照

WIP 模块（`wip.html` 看板 + `wip-config.html` 品类配置）是 7 大核心优势落地最集中的一块屏。下表逐条对照优势与 WIP 中的具体能力，交接演示时可按此顺序讲解。

| 我方优势（advantage.html） | 在 WIP 模块中的落地能力 |
| --- | --- |
| ① 多源数据打通，统一看 | 已接入客户真实《BE1 WIP Report-V26.xls》（`.extract-wip.py` → `wip-real-data.js`）；Earn 口径复用 OP 配置单价——大分类价 + 封装料号级单价（料号未配价自动回落大分类兜底价），OP / WIP 两屏价格口径统一；已落地的「COMP 塑封料出库解冻」以批次级解冻状态直接叠加进批次列表（已解冻 / 解冻中 / ⚠ 解冻超时 N h） |
| ② 批次全链路追溯 | 一级看板点击工序行 / 热力矩阵格即进入二级抽屉，下钻到批次号 / size / 封装料号 / 机台 / Bank / Hold（含原因）/ OTD 余量 / BE CT / 塑封料解冻（物料批号 + 起止时间）；多维筛选（pkg type / size / 封装料号 / 机台 / Bank / 仅看 Hold / 仅看解冻超时 / 关键字）+ 排序 / 分页 / Excel 导出 |
| ③ 数据口径统一、可对比 | 数量（K）/ Earn（万元）双口径一键切换；金额逐行按料号单价折算（不整体乘品类价），批次列表自带「金额（元）」列，与 Earn 口径联动；口径 / 筛选状态本地持久化 |
| ④ 异常告警 + 闭环联动 | BE CT（黄 7 天 / 红 14 天）与 OTD 逾期红线阈值本地可配，触发行整行高亮；Hold / OTD 逾期 KPI 带脉冲标记；排行站点在制超预警值标 ⚠；WIP 已纳入预警组件（alerts.html）的子系统 × 报警级别 × 联系人绑定，可联动设备报修 / 模具维修工单 |
| ⑤ OTD 周期监控 | KPI「OTD 逾期」= Shutdown 余量为负（已逾期）；排行条按工序展示 Hold / OTD 分布；二级抽屉默认按 OTD 余量升序（最急优先），配合 BE CT 天数识别在制最久批次 |
| ⑥ 可复用大屏 + 交接中心 | 5 项 KPI 数字滚动 + 工序 × PKG Type 热力矩阵（色深 = 品类在制占比、悬停明细）+ 工序排行堆叠条 + 自动巡检高亮；热力矩阵品类列头点击联动右侧排行按该品类客户指定站点清单重算（再点恢复全部）；纯静态离线可演示 |
| ⑦ 落地经验、非纸面方案 | COMP 塑封料出库解冻为我方已交付系统，其时效监控（解冻超时高亮 / 仅看解冻超时筛选）已在 WIP 批次列表实际演示；WIP 品类配置支持客户自行维护显示名 / 单价口径 / 矩阵显示 / 站点清单（拖拽排序 + 逐站点预警值），无需改代码 |

WIP 独有的差异化能力（超出客户初始需求的部分）：

- **人工 / 自动配批计算**：二级抽屉内「人工计算」（勾选批次弹出金额明细与总价）与「自动计算」（输入需求量或预算总价，按当前排序自动取批、末批部分取用，可手动增删批次后再次计算）——直接支撑出货 / 备料决策
- **站点级预警**：排行联动站点清单逐站点可配预警值（颗），超标即 ⚠ 标记
- **品类配置零开发**：数据中出现但未配置的品类自动按默认样式补齐；客户在 `wip-config.html` 即可完成显示名 / 单价口径 / 站点清单配置，即时生效
